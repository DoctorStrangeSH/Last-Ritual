# Ледяной обелиск — исходники эффектов

Текущий модульный кандидат VFX генерируется кодом `tools/generate_frost_modular_candidates.py`:
- обычный ледяной осколок и ледяной взрыв;
- усиленный снаряд и крупный раскол для специализации «Мороз»;
- веер осколков и снежный всплеск для специализации «Метель».

Каждый атлас содержит восемь неповторяющихся кадров на прозрачном фоне. Размеры кадров: 32×32 для projectile и 64×64 для impact. Оружейные projectile sheets направлены вдоль +X.

PNG-кандидаты находятся в `assets/spire/towers/frost/candidate/vfx/`. Они проверяются Python-тестами и Godot manifest contract, но не подключены к боевому рендереру.

Старые VFX в `assets/spire/towers/frost/vfx/` — отдельный действующий экспериментальный набор. Они не перезаписываются этим кандидатом. Ранние заметки о SVG-исходниках не подтверждают наличие SVG-файлов в Git; актуальный редактируемый источник — Python-генератор.
