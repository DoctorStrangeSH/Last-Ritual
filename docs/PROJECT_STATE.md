# Состояние проекта

Дата: 2026-10-28. **v0.6, код не проверен запуском в Godot.**
Репозиторий: DoctorStrangeSH/Last-Ritual, private, main.

## Имеется в коде
Вертикальный срез: один день осады (враги, две башни, ремонт), одна ночь (платформы, враги, мана, босс, Камень Бездны), алтарь, победа/поражение, пауза, души.

## Изменения v0.6
- Новый тип врага ночью: стационарный Маг Света с 60 HP, дистанционная атака снарядами каждые 2,2 сек в радиусе 520 px, 14 урона от попадания, награда 18 маны и 2 души.
- Снаряды создаются, перемещаются, удаляются при попадании и по таймеру жизни.
- Пользователь сообщил, что предыдущие сборки в GitHub Actions зелёные; статус сборки v0.6 и реальное прохождение пока не проверены.

## Изменения v0.5
- Ночная способность Shadow Dash на Shift: 125 px вперёд, 15 маны, 2,5 секунды перезарядка, 0,35 секунды защиты от урона, визуальный след. Это пока прототип перемещения без физического столкновения с препятствиями.
- Пользователь сообщает, что GitHub Actions зелёные. Независимой проверки игрового процесса в Windows ещё нет.

## Изменения v0.4
- Лечение H ночью: 20 маны за 30 здоровья, максимум 100.
- Хранитель совершает атаку с предупреждением (0,75 с), интервал между атаками 2,8 с; можно отойти.

## Изменения v0.3
- Ночной прыжок по W/Space с обнаружением первого нажатия.
- Направленная атака в сторону движения и короткий эффект удара.
- Убитые враги ночью больше не наносят контактный урон.
- Добавлены export_presets.cfg и .github/workflows/windows-build.yml для сборки Windows EXE через GitHub Actions.

## Проверка
Изменения загружены в GitHub. Доступные методы GitHub возвращают пустые списки для PR workflow/combined status, поэтому состояние push workflow не установлено. **Godot-импорт, сборка EXE в CI и игровое прохождение ещё не подтверждены.** Проверить Actions → Windows build и при сбое посмотреть логи.
