# Last Ritual — художественная библия (v1)

**Канон:** утверждённый владельцем концепт шести башен, 31.10.2026. Тёмное фэнтези, чёткий пиксель-арт, светящаяся магия, готические формы, каменные и металлические основания; высокий контраст объекта и фона. Это нормативный документ для новых художников/ИИ, а не утверждение, что концепт уже превращён в игровые спрайты.

## Визуальная формула
- Силуэт читается на 50% размера. Уровень 1 прост и низок; 2 — больше деталей и свечения; 3 — отчётливо выше/массивнее, но занимает ту же логическую игровую клетку.
- Материалы: тёмный камень с холодной гранью, патинированная бронза, кость, гравированные руны, яркая магия. Ручная пиксельная кладка, ступенчатые контуры, НЕ блюр и НЕ 3D-рендер поверх пиксельного UI.
- Источник света — магическое ядро/оружие башни. Глубокая тень, 2–4 оттенка на материал, локальные highlights, немного лёгкого свечения только внутри VFX.
- Объекты должны быть различимы не только оттенком, но формой, оружием и эффектами.
- Камера: top-down/3-4 псевдоизометрический ракурс, строго один согласованный угол на уровне; проверять совместимость с текущим Foozle перед импортом.
- Чернильные тёмные фоны и золотистые линии интерфейса. Русские подписи только в UI, не запекать их в PNG предметов.
- Существующие оригинальные Foozle PNG в `assets/spire/towers` — источник текущих четырёх базовых конструкций. Не заменять чужие исходники «стилизованным» концепт-листом.

## Компоненты башни
`BASE` (корпус уровня) → `WEAPON` (подвижная надстройка уровня) → `SPECIALIZATION_OVERLAY` (ветка, не перекрывает контур оружия) → `ATTACK_VFX` → `IMPACT_VFX`. Стройка/разрушение — отдельные **one-shot** анимации. Idle НЕ должен бесконечно проигрывать строительство или перебирать весь исходный атлас.

## Запрещено
- Бесконечная «анимация строительства», неполная башня, клиппинг/неверный pivot.
- Бледные одинаковые силуэты, случайные палитры, смена угла камеры от башни к башне.
- Блики/свечение, скрывающие контуры на масштабе 1×.
- Тексты и декоративные фоны внутри прозрачных игровых ресурсов.
- Перепутать `projectiles` (летит) и `weapon_impact` (столкновение).

## Контроль качества
Игровой кадр: все шесть башен Lv1 / Lv2 / Lv3 + обе специализации, на светлой и тёмной сцене, показ без UI и с UI; проверка nearest/pivot, читаемости при zoom 1×, fps/memory; сравнение с иконками в `assets/spire/towers/*/specializations/*/icon.svg`. До завершения такого теста ассет считается «кандидат», не «готов к релизу».


## Pixel Art production rules (v2)

The owner confirmed that the **entire game**, not only the six towers, must use one cohesive, detailed, hand-authored dark-fantasy Pixel Art style. The binding technical standard is [`PIXEL_ART_STYLE_GUIDE.md`](PIXEL_ART_STYLE_GUIDE.md). Do not use a pixelation filter on realistic assets as the final solution. New tower kits must have static base + pivot-consistent aiming upper layer, explicit directional pose/rotation metadata, animated projectile and one-shot impact sheets, editable source, PNG export and manifest. Use Nearest filtering and integer scaling after verifying compatibility with the current Godot viewport. Existing realistic assets remain temporary during staged migration and may be deleted only after replacement, reference audit and QA.
