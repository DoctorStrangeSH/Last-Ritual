# Алтарь душ: новый оригинальный комплект в runtime

Вместо геометрических SVG-подстановок рендер теперь готов использовать **оригинальные детализированные PNG**, вырезанные из утверждённого концепта v0.5.

## Контракт игровых PNG
В каталог assets/spire/towers/necro/production/ требуется импортировать полный проверенный набор из SoulAltar_Full_Art_Pack.zip посредством tools/install_necro_full_pack.py:
- level_1_192.png, level_2_192.png, level_3_192.png (192x192);
- specialization_reaper_192.png и specialization_legion_192.png (192x192);
- level_1_idle_8f.png, level_2_idle_8f.png, level_3_idle_8f.png (1536x192; 8 кадров);
- soul_projectile_8f.png (512x64; 8x64x64);
- soul_impact_8f.png (1024x128; 8x128x128).

Исходник v0.5: SHA256 fa73a1ff2e771c2bc5c7a4df7be04b71654f1d802fe2645e3451df0da641db40. Его следует сохранить неизменным.

## Поведение
Рендер переключается на оригинальные изображения только при наличии ВСЕХ требуемых PNG. Уровни, Жнец/Легион и 8 кадров анимаций поддерживаются без изменения баланса/сохранений. Пока файлы отсутствуют, остаётся проверенный fallback.

**Честный статус:** этот PR пока не переносит бинарные файлы из локального архива. Без их коммита в Git main никакой новый EXE не содержит оригинальный арт. Удаление старых временных текстур возможно только после успешного импорта и CI.

VFX созданы из текстуры исходного зелёного пламени, но требуют отдельной художественной и игровой приёмки.
