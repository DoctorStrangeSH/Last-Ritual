## Контракты первых игровых сцен
**P1 / ночь:** отдельная `scenes/topdown_night_prototype.tscn`; сцена запускается непосредственно из Godot, не трогает сохранения. Игрок движется WASD в 8 направлениях и прицеливается мышью. Минимум три связанных комнаты, два врага, одна выбираемая награда, базовая атака и короткий рывок. Тест: переходы, урон, победа, отсутствие застревания и получение награды ровно один раз.

**P2 / день:** отдельная top-down сцена цитадели. Два маршрута, три типа башен, три волны. Башни ставятся только на неизменяемые ID площадок (free/occupied/locked). Строительство выбирается мышью; hover показывает радиус, клик по построенной башне — upgrade/sell; на маршруты и вне площадки строить нельзя. Тест: свободный/занятый/заблокированный слот, покупка, продажа, отсутствие перекрытия маршрутов.
