## Простая загрузка (GitHub issue #300)
1. Скачать ZIP по ссылке в сообщении ChatGPT.
2. Открыть `https://github.com/DoctorStrangeSH/Last-Ritual/issues/300`.
3. Написать новый комментарий, который **начинается с** `IMPORT_SOUL_ALTAR_V05`, и прикрепить ZIP в поле комментария. GitHub автоматически вставляет ссылку на `github.com/user-attachments/...`.
4. Workflow `.github/workflows/import-necro-original-bundle.yml` проверит имя владельца issue-комментария, проверит точный SHA256, CRC и **все PNG** по manifest, сравнит оригиналы с HD копиями и запишет файлы в отдельную review-ветку.
5. После этого отдельный PR и успешный Godot+Windows CI позволяют внедрить графику в main; лишь тогда удалять упрощённые заглушки.

Такой процесс не требует раскладывать PNG вручную, не меняет основную ветку по одному комментарию, и не использует квоту Actions Artifacts.

Ручная художественная QA и окончательное утверждение анимаций остаются открытыми. Снаряд и удар из полного пакета — текстурированные кандидаты, сделанные из исходного зелёного пламени.
