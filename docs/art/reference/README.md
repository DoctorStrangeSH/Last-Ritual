# Референсы и контроль качества

- `reference/` — художественные ориентиры, включая ссылку на исходный чат/изображение и пометку «concept only».
- `approved/` — только проверенные внутри Godot прозрачные игровые текстуры и контактные листы, подтверждённые владельцем.
- `rejected/` — примеры, от которых осознанно отказались, с указанием причины.
- Перед продолжением другим ИИ: изучить `STYLE_BIBLE.md`, `ASSET_SPEC.md`, `PROMPT_LIBRARY.md`, `SIX_TOWER_VISUAL_IDENTITY.md` и 12 утверждённых `icon.svg`.
- Концепты шести башен, созданные в чате 31.10.2026, пока не закоммичены как исходные большие PNG. Не считать их локально доступными следующему ИИ без отдельной загрузки/сохранения в репозиторий.
