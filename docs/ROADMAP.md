# Last Ritual — дорожная карта 2.0 (ТОЛЬКО ВИД СВЕРХУ)

**Решение владельца: 29.10.2026.** Пользователь подтвердил, что скачал классический EXE и разрешил удаление старых исходников; постоянный GitHub Release не обязателен. Единственная целевая игра — **top-down action roguelite + tower defense**. Старые S0–S8, T1–T4 и R1–R7 **сняты с повестки**, не являются задачами и не требуют отметок; прежнюю платформенную кампанию не поддерживаем. Вдохновение глубиной синергий The Binding of Isaac: Repentance+, но без копирования контента, графики и сюжетных решений.

**Игровая фантазия:** днём герой защищает Ритуальный Алтарь в стратегической top-down TD-обороне; ночью исследует процедурные комнаты, получает предметы, усиливает героя и башни. Один забег связывает обе части. Башни ставятся **только на заранее обозначенные строительные площадки**.

## Правила реализации
1. Следовать **V0 → V1 → V2 → V3 → V4 → V5**; дальнейшее `Дальше` означает следующий незавершённый пункт, а не возобновление классического проекта.
2. Малые PR, Godot 4.4.1, headless smoke, зелёный CI PR HEAD и проверка CI `main` после merge; отмечать ручной QA отдельно.
3. **Никакого возвращения к платформеру.** Переиспользуем только данные/код, полезные новой игре; классика остаётся EXE.
4. Владелец подтвердил сохранение классического EXE и разрешил удаление старых исходников. Не заменять это утверждением, что EXE проверен запуском.
5. Подробнее игровой дизайн — `docs/TOPDOWN_REBOOT.md`; историческая миграционная инвентаризация — справка, не активный план.
