# Алтарь душ — утверждённый Pixel Art

Это уже выбранный владельцем дизайн. Новые концепты Алтаря душ не создаются.

## Production atlas
- Файл: `soul_altar_approved_atlas.png`
- Размер: 320×88 px, пять горизонтальных кадров по 64×88 px.
- Порядок: уровень 1, уровень 2, уровень 3, Жнец, Легион.
- Игровой TD-рендерер выбирает нужную ячейку и рисует её в размере 128×176 px (2× nearest-neighbour).
- PNG индексированный, с настоящей прозрачностью палитры; фон ячеек прозрачен.

## Экспорт отдельных кадров
Из корня репозитория:

```bash
python -m pip install Pillow
python tools/export_soul_altar_approved_atlas.py
```

Скрипт проверяет размер atlas и alpha, извлекает пять отдельных PNG 64×88 и их nearest-neighbour версии 2×.

## Исходники и ограничения
- Утверждённый референс: `assets/spire/towers/necro/source/concepts/soul_altar_tower_concept_v05.png`.
- Production raster source: сам atlas PNG; его можно редактировать в любом редакторе изображений.
- Высокодетальные generated source PNG находятся в review ZIP, а не отдельными Git-файлами.
- Отдельный Aseprite/PSD с независимыми слоями не предоставлен; фиктивный проект не создаётся.
- Это первая runtime-интеграция пяти цельных силуэтов. Отдельная неподвижная база, верхнее оружие с 8 направлениями, пиксельные снаряды/импакты и idle/build/sell ещё впереди.
- Поэтому модульный manifest contract остаётся `runtime_enabled=false`. Старые не-SVG runtime ресурсы не удалять до полной модульной замены и ручной проверки Windows EXE.
