# Last Ritual — план полноценного перезапуска игрового опыта (29.10.2026)

Статус: **утверждённое направление разработки, не реализованные фичи**. Источник истины для задач — ROADMAP.md; текущий код — прототип, не готовая игра. Референс Isaac — структура исследований и вариативность, не копирование контента.

## Почему текущая игра пока не работает
- Две геометрически прямые линии TD с восемью фиксированными слотами дают мало решений о маршрутах, позиционировании и приоритетах.
- Ночь — три последовательные боевые арены; выбор текстовой карточки после боя **не является** физическим исследованием графа комнат.
- Хаб и UI в основном рисуются Node2D._draw() с фиксированными координатами 1152×648; практически нет отдельной визуальной иерархии, адаптации к окну и игровых анимаций.
- Системы содержательны (прокачка, реликвии, телеграфы, укрытия, враги), но небольшие фичи не заменяют переработку базового игрового цикла.

## Вертикальный срез, который стоит сделать первым
**Крепость:** один вручную спроектированный оборонительный уровень 1152×648 с двумя реально изгибающимися, пересекающимися по зонам огня, но не блокирующими друг друга маршрутами; минимум 2 разветвления угроз/точки входа, общая финальная цель, 10–12 осмысленных строительных площадок по разные стороны дорог. Башни строятся только на площадках и выбираются исключительно мышью. Перед волной игрок видит стрелки маршрутов, прогноз врагов и возможность подготовиться; между волнами — понятная фаза строительства. Добавить 3 интересные волны, разные сопротивления и контрмеры, хотя бы один уникальный риск/награду. Не путать количество линий с качеством TD.

**Ночь:** один настоящий этаж с 8–12 узлами и связным seed-графом: старт, бои, событие, магазин/сокровищница, элита, босс, выход. Герой *физически* проходит дверные проёмы с северной/южной/восточной/западной стороны, стены ограничивают перемещение и снаряды, камера/переходы очевидны. Комнаты остаются на карте после посещения, дверь закрывается на время боя; при возвращении враги не возрождаются. Обязательные комнаты достижимы, тупиков без способа выхода нет. Выбор маршрута делается через двери и карту, а не четыре карточки после каждой арены.

**Сквозной цикл:** день → короткий экран итогов обороны и выбор усиления → ночь → найденные реликвии и ресурсы непосредственно меняют следующую оборону → следующий день. Без обязательного возвращения в главное меню между фазами; хаб — отдельный экран для начала/продолжения, настроек, прогресса. Смерть завершает забег, метапрогресс сохраняется отдельно.

## Визуальный стандарт
- 2D top-down dark fantasy: холодный камень, серо-фиолетовые стены, тёплая кровь/руны, бирюзовые эффекты союзников, золото интерактивных предметов. Контраст угроз выше фона.
- Использовать законно лицензированный целостный набор тайлов и спрайтов; зафиксировать автора, URL, лицензию и атрибуцию в assets/CREDITS.md. Не копировать Isaac. Не импортировать произвольные плагины и ассеты без проверки лицензии и совместимости Godot 4.4.1.
- Перейти от преимущественно _draw() к TileMapLayer/TileSet для уровней, CharacterBody2D/Area2D для сущностей и Control/Container/Theme для UI; переносить поведение постепенно через адаптеры и тесты, не переписывать монолиты за один PR.
- Главное меню: НОВЫЙ ЗАБЕГ, ПРОДОЛЖИТЬ (только при наличии валидного сейва), РЕЛИКВИИ/ДОСТИЖЕНИЯ, УЛУЧШЕНИЯ, НАСТРОЙКИ, ВЫХОД; заметная центральная иллюстрация, анимированный фон без мешающего текста.
- HUD дня: крепость/HP, золото, волна и превью угроз сверху; башни снизу; подробности выбранной башни — только по клику. HUD ночи: HP/ресурсы/заряды и мини-карта; описание предмета только рядом/по наведению. Клавиатура не обязательна для навигации по меню.
- Читабельные попадания, силуэты, телеграфы, эффекты с лимитами; на 1152×648 ничего не перекрывает боевую зону.

## Предпочтительная последовательность PR
1. **TD геометрия и маршрутные тесты**: заменить две прямые на настоящую карту с изгибами/заходами и гарантией от перекрытий/застреваний; только потом наращивать башни.
2. **TD фазы и решения**: строительство/волна/итоги, роли угроз, информация о маршруте, правила размещения.
3. **Ночной граф данных**: генерация и валидация достижимости, seed, тесты без визуального рефакторинга.
4. **Ночные двери и стены**: физические переходы между соседними комнатами, backtracking, очищенные комнаты, босс и выход.
5. **Новый визуальный фундамент**: единый TileSet и арт-направление (начать с одной сцены дня и одной ночи), затем персонажи и VFX.
6. **Новый UI и меню**: Control/Theme, mouse-first, экран фаз, пауза и настройки, адаптация разрешений.
7. **Синергии и баланс**: 3 различимых билда, связь day/night, 15–25 минут на первый содержательный забег.
8. **Проверка**: headless smoke и Windows export в CI, ручной проход день → ночь → день с записью скриншотов и дефектов.

## Критерии приёмки
- Нельзя завершить «ночь» последовательным нажатием на карточки, не исследовав комнаты.
- Оборона предлагает разное выгодное позиционирование как минимум для трёх башен; враги реально поворачивают и доходят до алтаря.
- В полном забеге ночные находки влияют на следующий день.
- Нет скрытого автоматического старта волны или перехода через экран: игрок принимает ясное решение; подсказка короткая.
- Проверены: отсутствие блокировки маршрутов, связность графа, отсутствие дублирования наград, корректный сейв, масштаб UI и Windows EXE.
- **Проверка Godot CI не равна ручному playtest.**
