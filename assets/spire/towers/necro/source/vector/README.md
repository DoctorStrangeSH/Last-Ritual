# Soul Altar — editable original SVG tower candidates

Three newly drawn 128×128 transparent SVG tower candidates live in this directory. Each is **an editable pixel-vector source**, using discrete solid-color geometry and `shape-rendering="crispEdges"`. They are independent of the user's immutable PNG concept sheet (see `docs/art/NECRO_SOURCE_V05.md`).

- `soul_altar_level_1.svg` — compact altar with one central flame.
- `soul_altar_level_2.svg` — taller construction, side supports, added skull ornaments.
- `soul_altar_level_3.svg` — tallest version, additional horns, necrotic braziers and skull ornaments.

**Status: artwork candidates, not Godot-approved gameplay sprites.** These are assembled tower concepts, not separated base/weapon textures. Do not update the `necro` runtime art mapping until individually prepared `base/level_1..3`, `weapon/level_1..3`, attack and impact textures pass visual QA and Godot smoke tests.

Palette/material cues: old bronze, cold dark stone, bleached bone and saturated spectral green; consistent 128×128 viewBox and ground footprint. The full untouched v0.5 PNG is still external to Git pending binary upload. This directory preserves genuine source geometry in Git.
