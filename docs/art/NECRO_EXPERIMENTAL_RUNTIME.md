# Алтарь душ: экспериментальная интеграция основания и оружия

**Актуализация 01.11.2026:** experimental PNG остаются в репозитории и `NECRO_EXPERIMENTAL_ART=true`, но это не означает, что они сейчас отображаются вместо утверждённых башен. `draw_tower_figure()` сначала выбирает цельные approved PNG L1/L2/L3/Жнец, затем production PNG Легиона; experimental base/weapon слои достигаются только как последний fallback. Они не являются утверждённым модульным комплектом и не дают восьми направлений. См. `necro_full_tower_sprite_path()` и `docs/ROADMAP.md`.


Этот этап добавляет **включённый для тестирования** preview-рендер настоящих импортированных бинарных PNG — теперь игровая башня `necro` может использовать собственную пару base/weapon, не alias `pulse`.

## Сохранённые бинарные ресурсы
Файлы `assets/spire/towers/necro/experimental/`:
- `base_level_{1,2,3}.png` — три 128×128 основания;
- `weapon_level_{1,2,3}.png` — три 128×128 оружия;
- `specialization_siege_level_3.png` — Жнец, составное PNG;
- `specialization_swarm_level_3.png` — Легион, составное PNG.

Изображения перенесены через Git blob SHA из snapshot review-ветки `art/necro-png-preview-a466342bf7f0`. Редактируемые SVG остаются в `source/layers/`. Оригинальный художественный концепт пользователя v0.5 ещё требуется опубликовать отдельным бинарным файлом.

## Важно
Это **экспериментальная графика**, не окончательная художественная приёмка. `NECRO_EXPERIMENTAL_ART := true` в `td_tower_visuals.gd` позволяет просмотреть башню в Windows EXE. При плохой читаемости или заметных расхождениях с референсом установить `false` — вернутся прежние базы и оружие. Снаряды и попадания остаются собственными, ранее введёнными VFX атласами.

Два слоя имеют одинаковые origin/canvas 128×128 и рисуются в одном Rect2. Специализации уровня 3 — готовые собранные варианты и рисуются **вместо** пары слоёв во избежание удвоения пикселей. Все четыре gameplay IDs, цена, урон, сохранения не изменены.
