# Последний ритуал · Last Ritual

Мрачная 2D-игра на Godot 4: днём защищай крепость башнями, ночью исследуй подземелье за Камнем Бездны, затем выбирай награду и готовься к следующему дню. После пятой ночи нужно пережить финальный штурм.

## Текущее состояние

- Основная ветка: main.
- Последний игровой этап: RC68 — Проклятый стрелок. Объединён в main после успешных PR-проверок.
- Post-merge workflow для main commit 91f829a прошёл успешно ([run #40816997661](https://github.com/DoctorStrangeSH/Last-Ritual/actions/runs/40816997661)).
- Полный ручной проход и визуальная проверка в запущенном Godot не подтверждены. Не считать CI заменой игровому тестированию.

## Запуск

1. Установи Godot 4.4.1 Standard (не .NET).
2. Открой project.godot через Project Manager.
3. Дождись импорта ресурсов и нажми F5 (Run Project); основная сцена настроена в project.godot.

## Управление

- **Днём:** мышью выбирай карту башни снизу; перетаскивай её на свободную линию, чтобы построить. Нажми на башню для выбора, затем используй панель улучшения/продажи. R — ремонт стены.
- **Ночью:** A/D или стрелки — движение; W/Space — прыжок; ЛКМ — атака в сторону курсора; ПКМ — Теневой рассекатель; Shift — рывок; H — лечение.
- **Алтарь:** мышью покупай улучшения и подтверждай переход; Enter — основное действие; C — обмен маны на душу.
- **Меню:** все основные разделы доступны мышью. Enter начинает/подтверждает действие; L пытается загрузить сохранённую кампанию.
- **Общее:** P — пауза; M/N — громкость атмосферы/эффектов.

## Реализовано в коде

- Пять дневных осад и пять ночных уровней, Камни Бездны и 45-секундный финальный штурм.
- Три типа башен, выбор линии, строительство, улучшение и продажа.
- Ночные платформы, ловушки, ресурсы, хранитель, Маг Света, Проклятый громила и Проклятый стрелок с телеграфируемыми атаками.
- Главное меню, продолжение сохранённой кампании, выбор сложности, достижения, постоянные улучшения, таланты, награды забега и легендарный дар.
- Контрольные сохранения у алтаря с проверкой входных данных; отдельные настройки звука.
- SVG-ресурсы, процедурные эффекты и звуковые сигналы.

Это перечень реализованного кода, а не гарантия идеального баланса или отсутствия визуальных ошибок.

## Проверки и Windows-сборка

Workflow: .github/workflows/windows-build.yml. Он импортирует ресурсы и проверяет скрипты в headless Godot, запускает tests/campaign_smoke.gd и экспортирует Windows EXE. Актуальный статус смотри в **Actions → Windows build**. Артефакт LastRitual-Windows публикуется только при успешном workflow.
