# Визуальные специализации — шесть башен Last Ritual

Статус: авторский **концепт-арт создан** в чате 31.10.2026. Концептные изображения содержат подписи/композицию; их нельзя напрямую подставить в Godot как отдельные кадры или прозрачный sprite sheet. Для игрового использования необходимо извлечь или перерисовать спрайты, проверить прозрачность, pixel grid, геометрию и масштаб, сохранить исходники в репозитории.

## Арт-дирекция / готовые идеи

| Башня | Основной цвет | Путь A (siege) | Путь B (swarm) | Визуальное отличие |
|---|---|---|---|---|
| Баллиста `ballista` | кость/бронза | **Осадная** | **Рой костей** | массивная двойная баллиста против ряда малых болтов |
| Огненная турель `fire` | оранжевый | **Инферно** | **Искры** | большой огненный взрыв против серии огненных искр |
| Искровой разрядник `spark` | синий/бирюзовый | **Цепная молния** | **Перегрузка** | перескакивающие дуги против мощного заряда |
| Импульсный излучатель `pulse` | фиолетовый | **Гравитация** | **Резонанс** | воронка притяжения против повторных концентрических волн |
| Алтарь душ `necro` | некрозелёный | **Жнец** | **Легион** | коса/поглощение душ против призванных скелетов |
| Ледяной обелиск `frost` | голубой/белый | **Мороз** | **Метель** | усиленное замедление против ледяного разлёта |

## Правила производства

1. У каждой башни есть три уровня **основания** и **оружия**, отличные текстуры projectile и weapon_impact. Для каждой специализации нужны минимум две раздельные иконки и отличимый игровой оверлей (например, надстройка/свечение), без изменения конструкции исходного Foozle вне её лицензии.
2. Концептные листы — направление по цвету и силуэтам, а не исходные PNG. Не коммитить лист целиком в `assets/spire/towers` как якобы игровой спрайт.
3. Дополнительные эффекты: `assets/spire/towers/<id>/specializations/siege/` и `.../swarm/`; при необходимости сохранить разные кадры для уровней 2 и 3 и подпись с source metadata.
4. Важно разделять **боевая специализация** и **её оформление**. Установку/переключение UI, боевой баланс и шесть отдельных игровых ID следует внедрять отдельным PR с smoke tests.
5. На текущий момент в игре только четыре боевых ID `bone`, `fire`, `necro`, `frost`. Из загруженных спрайтов они временно показывают `ballista`, `fire`, `pulse`, `spark`. Расширение до шести ID и перерисованные `necro/frost` пока **не реализованы**.
6. Для ранней стадии разрешено не обеспечивать миграцию старых сохранений, по согласованию с владельцем. Но не менять игровой баланс без тестов и игрового прототипирования.
