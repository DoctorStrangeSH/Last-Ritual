# Последний ритуал — Пролог (v0.2)

Мрачный 2D-прототип для Godot 4.2+ без сторонних плагинов и ассетов. День: Tower Defense; ночь: платформер; затем ритуал.

## Запуск
1. Склонировать репозиторий или скачать ZIP через Code → Download ZIP.
2. Godot 4.2+ (не .NET) → Import → выбрать project.godot.
3. Открыть проект, F5, на заставке Enter.

## Управление
День: 1 — костяная башня (30 маны), 2 — адская баллиста (55 маны) в позиции курсора (правее крепости); R — ремонт стены за 20 маны. Ночь: A/D или стрелки — движение; W или Space — прыжок; J — атака. Победить хранителя, взять Камень Бездны и вернуться к порталу слева. Алтарь: C — 25 маны → 1 душа; Enter — ритуал при наличии камня, 50 маны и 8 душ. P — пауза. После победы/поражения Enter — новая попытка.

## Статус
Прототип рассчитан на **один день, одну ночь и один ритуал**. Пятидневная кампания пока планируется. Процедурная графика, звуки и сохранения отсутствуют. **Запуск на Godot не проверен:** доступен только исходный код. Ошибки при импорте фиксировать в docs/PROJECT_STATE.md.
