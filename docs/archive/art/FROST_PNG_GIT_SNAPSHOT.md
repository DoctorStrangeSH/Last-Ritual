# Снимок PNG-кандидатов Ледяного обелиска

Исходники SVG уровней I–III и анимаций сохранены в `main`. Workflow `.github/workflows/frost-png-snapshot.yml` экспортирует **11 настоящих PNG** через Godot 4.4.1 и создаёт отдельную review-ветку `art/frost-png-preview-<SHA>`.

В ней хранится `assets/spire/towers/frost/source/generated-preview/`: 3 основания, 3 оружия, 3 собранных башни; в `vfx/` — два атласа снаряда и попадания. `SOURCE_COMMIT.txt` связывает файлы с исходным SHA, `SHA256SUMS.txt` позволяет проверить целостность бинарных PNG.

**Важно:** это экспериментальная графика, не утверждённая художественно. Рендер текущей игровой башни и сохранения не меняются. Review-ветка не сливается автоматически в `main`; до интеграции требуется визуальный осмотр, затем отдельный PR с безопасным переключателем/откатом.

Workflow не использует квоту GitHub Actions Artifacts и запускается при добавлении самого файла workflow в `main` либо вручную.
