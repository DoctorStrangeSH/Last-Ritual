# Алтарь душ — модульный пиксельный прототип (НЕ УТВЕРЖДЁН)

Эти PNG нарисованы отдельно пиксельной геометрией по 16-цветной палитре. Это реальные растровые рисунки, а не фильтр пикселизации старого концепта. **Их текущий художественный уровень — только рабочий серый прототип, не финальный стиль игры.** Переключать runtime на них запрещено без отдельного решения владельца.

## Комплект
- `base/level_1.png`, `base/level_2.png`, `base/level_3.png`: три самостоятельных основания 128×128 RGBA/indexed, неподвижны, различимы по деталям и силуэту.
- `weapon/base/weapon_8way.png`: 8 поз алтарного оружия, каждая ячейка 128×128.
- `weapon/reaper/weapon_8way.png`: 8 поз косы Жнеца.
- `weapon/legion/weapon_8way.png`: 8 поз тройного оружия Легиона.
- Все экспортированные текстуры хранятся **в Git**. PNG может редактироваться попиксельно в LibreSprite или Aseprite. **Отдельного многослойного Aseprite-файла пока нет, он не выдуман.** Генерация первого набора была выполнена процедурно на основе геометрических пиксельных форм; отдельный воспроизводимый исходный скрипт этого чернового набора не сохранён, поэтому для будущей переработки PNG является исходным растром.

## Палитра
Чёрный камень `#151125`, сланец `#292137`, камень `#41364C`, золото `#BC955C`, яркое золото `#F4C87D`, тёмная магия `#2A1140`, магия `#971FB7`, свечение `#D45DF8`, блик `#FFB8FB`. Прозрачный фон индексного PNG.

## Совмещение
- Размер любого base: 128×128; размер weapon strip: 1024×128 (8 ячеек по 128×128).
- Канонический порядок: север, северо-восток, восток, юго-восток, юг, юго-запад, запад, северо-запад.
- Общее полотно, pivot `(64,90)`, ground anchor `(64,118)`.
- Корпус и основание всегда рисуются в одном прямоугольнике. Нельзя вращать целую башню.
- Временное оружие имеет явную направленную форму для каждого направления; детализировать геометрию и фактуру до художественной приёмки.

## Безопасность
- `candidate/manifest.json` — **отдельный** манифест для проверок, `runtime_enabled=false`.
- Рабочий `assets/spire/towers/necro/manifest.json` не меняется.
- Проверка `tests/soul_altar_modular_candidate_smoke.gd` запускается в GitHub Actions и проверяет настоящие PNG/альфу/размеры/8 различимых кадров, но **не доказывает художественного качества**.
- После утверждения нужно адаптировать сложные согласованные фиолетово-золотые силуэты и детали; предварительный рисунок сейчас ощутимо проще действующего approved sprite.
- В конце ручное Windows 1× QA. До этого старые ассеты не удалять.

## Дальше

4. **Только после одобрения** перенести ресурсы из candidate/ в production base/ и weapon/, включить манифест и проверить бой.
