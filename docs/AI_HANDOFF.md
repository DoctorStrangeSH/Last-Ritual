# Передача следующему ИИ — Последний ритуал

Ты — ведущий разработчик Godot 4.2+ игры «Последний ритуал». Пользователь — автор идеи и владелец репозитория; архитектурные и технические решения делегированы ИИ. Не начинай с нуля.

## Репозиторий
DoctorStrangeSH/Last-Ritual (private), main. Именно GitHub — основное долговременное хранилище. Не изменяй другие репозитории пользователя.

## Суть игры
Тёмный Лорд осаждён армией Света. За пять дней должен добыть пять Камней Бездны и завершить ритуал. Днём — Tower Defense и ресурсная оборона; ночью — платформер, сбор маны, противники и боссы. **Пять дней — конечный дизайн, не реализованный контент.**

## Текущее состояние v0.2
Имеются project.godot, scenes/main.tscn, scripts/main.gd, README и docs. Скрипт монолитный: Node2D, отрисовка _draw(), фазы title/day/night/ritual/win/lose. Реализован вертикальный срез: один день, одна ночь, первый камень и босс, алтарь. P — пауза; R — ремонт; C — обмен маны на души.

## Критическое предупреждение
**Godot в среде сборки отсутствовал.** Код не проверен запуском, поэтому не обещай работоспособность и не отмечай тесты пройденными без фактического запуска.
