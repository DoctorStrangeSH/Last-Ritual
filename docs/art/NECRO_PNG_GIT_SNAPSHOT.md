# Хранение экспортированных PNG Алтаря душ непосредственно в Git

До этого момента редактируемые SVG лежали в `main`, а экспортированные PNG — только в Releases. Для разработки этого недостаточно: хочется сохранять реальные бинарные промежуточные изображения и видеть, какой коммит исходников их породил.

Новый `.github/workflows/necro-png-snapshot.yml` выполняет Godot headless export и сохраняет **12 PNG** (11 игровых кандидатов и `contact_sheet.png`) в **отдельную review-ветку** `art/necro-png-preview-<SHA>`, в каталог:

`assets/spire/towers/necro/source/generated-preview/`

Сопутствующие файлы: `SOURCE_COMMIT.txt` с точным исходным коммитом и `SHA256SUMS.txt` для проверки неизменности каждого PNG.

Правила безопасности:
- Workflow стартует при попадании **самого workflow** в `main` либо вручную, а не при любом запуске игры.
- Никогда не вносит автоматически изображения в `main` и не меняет runtime-картинки.
- Не заменяет пользовательский оригинальный концепт `v0.5`, который требуется сохранять отдельно.
- Если GitHub Actions не имеет разрешения создавать review-ветки, workflow завершится ошибкой. Без успешного выполнения нельзя утверждать, что PNG записаны в Git.
- Этим кандидатам ещё требуется художественная приёмка; визуальный эталон — утверждённые пользователем референсы.

Это **снимок** из конкретного коммита, а не автоматический pipeline доставки production-арта.
