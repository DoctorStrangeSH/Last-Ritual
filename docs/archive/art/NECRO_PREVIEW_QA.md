# Автоматическая проверка различимости арта Алтаря душ

Godot-экспортёр `tools/export_necro_layers.gd` теперь дополнительно проверяет, что **основания и оружие уровней I/II/III различаются**, а «Жнец» и «Легион» действительно меняют пиксели собранной башни третьего уровня.

Порог: не меньше 25 отличающихся RGBA-пикселей (128×128) для каждого соседнего уровня одного слоя и каждой специализации относительно собранной L3. Это страховка от ошибок конфигурации, пустых оверлеев и случайно повторно используемого файла; порог не доказывает художественного качества.

Проверка работает без сторонних Python-зависимостей в стандартном шаге Godot CI. Результирующие предпросмотры остаются доступны по адресам:

- [Контактный лист](https://github.com/DoctorStrangeSH/Last-Ritual/releases/download/windows-preview/contact_sheet.png)
- [Архив 11 PNG и контактного листа](https://github.com/DoctorStrangeSH/Last-Ritual/releases/download/windows-preview/SoulAltar-art-preview.zip)

**Статус:** визуальная приёмка и перенос оригинального PNG v0.5 в Git всё ещё не завершены. Эта автоматическая проверка не даёт разрешения подключать художественные кандидаты в runtime.
