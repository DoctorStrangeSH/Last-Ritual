## Комплект
- `base/level_1.png`, `base/level_2.png`, `base/level_3.png`: три самостоятельных основания 128×128 RGBA/indexed, неподвижны, различимы по деталям и силуэту.
- `weapon/base/weapon_8way.png`: 8 поз алтарного оружия, каждая ячейка 128×128.
- `weapon/reaper/weapon_8way.png`: 8 поз косы Жнеца.
- `weapon/legion/weapon_8way.png`: 8 поз тройного оружия Легиона.
- `vfx/{base,reaper,legion}_projectile_8f.png`: три 8-кадровых снаряда (32×32 для base/Legion, 48×48 для Жнеца).
- `vfx/{base,reaper,legion}_impact_8f.png`: три 8-кадровых попадания (64×64 для base/Жнеца, 48×48 для Легиона).
- Все экспортированные текстуры хранятся **в Git**. PNG может редактироваться попиксельно в LibreSprite или Aseprite. **Отдельного многослойного Aseprite-файла пока нет, он не выдуман.** Исходник генерации теперь сохранён в `tools/generate_necro_modular_candidates.py` (чистая геометрия + Pillow); `--verify` сверяет реальные RGBA-пиксели всех 12 PNG с воспроизводимой генерацией. Для переработки можно изменить скрипт и перегенерировать PNG; художественную приёмку это не заменяет.

## Совмещение
- Размер любого base: 128×128; размер weapon strip: 1024×128 (8 ячеек по 128×128).
- Канонический порядок: север, северо-восток, восток, юго-восток, юг, юго-запад, запад, северо-запад.
- Общее полотно, pivot `(64,90)`, ground anchor `(64,118)`.
- Корпус и основание всегда рисуются в одном прямоугольнике. Нельзя вращать целую башню.
- Временное оружие имеет явную направленную форму для каждого направления; детализировать геометрию и фактуру до художественной приёмки.

## Безопасность
- `candidate/manifest.json` — **отдельный** манифест для проверок, `runtime_enabled=false`.
- Рабочий `assets/spire/towers/necro/manifest.json` не меняется.
- Проверка `tests/soul_altar_modular_candidate_smoke.gd` запускается в GitHub Actions и проверяет настоящие PNG/альфу/размеры/8 различимых кадров, но **не доказывает художественного качества**.

- В конце ручное Windows 1× QA. До этого старые ассеты не удалять.
