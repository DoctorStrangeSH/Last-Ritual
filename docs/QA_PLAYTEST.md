# Last Ritual — ручной QA перед релизом

**Статус:** чек-лист для будущего тестирования, не отчёт об уже выполненном тесте. Успешный GitHub Actions (импорт Godot 4.4.1, smoke-тесты, Windows EXE) подтверждает автоматическую сборку, **но не заменяет ручной игровой прогон**.

## Подготовка
1. Открыть последний успешный запуск [Windows Build](https://github.com/DoctorStrangeSH/Last-Ritual/actions/workflows/windows-build.yml) для ветки `main`; скачать артефакт Windows EXE.
2. Зафиксировать номер Actions run, коммит SHA, Windows/разрешение экрана, дату и настройки громкости.
3. Проверять в размере 1152×648, а затем в меньшем окне. Старый классический EXE к этому тесту не относится.
4. Перед экспериментами с сохранениями сохранить резервную копию файлов игры из `user://`; **не удалять пользовательский прогресс ради проверки**.

## Критический путь (Normal)
- [ ] В главном хабе все кнопки доступны мышкой, выбранная сложность выделена, текст не перекрывается.
- [ ] День 1: выбрать башню мышью, построить её на площадке, выбрать башню, улучшить, продать, начать волну.
- [ ] Пройти три волны: отображаются здоровье алтаря, золото, враги разных типов и предупреждение атаки босса.
- [ ] При подготовке удара босса нанести два удара героем и убедиться, что атака отменяется; в другой попытке проверить урон алтарю.
- [ ] После победы выбрать награду забега мышью и перейти в ночь.
- [ ] Ночь: WASD/стрелки, ЛКМ атакует, получение урона видно, смерть врага даёт душу.
- [ ] Реликвии можно выбирать ЛКМ, нельзя получить одну награду дважды.
- [ ] После зачистки доступны маршруты: лечение, элитный бой, проклятый алтарь и торговец. Цена выбора соответствует описанию.
- [ ] Сравнить тактику комнат CRYPT / AMBUSH / ELITE: у засады две быстрые атакующие цели с разных сторон, у ELITE чемпион выдерживает больше ударов и атакует медленнее, но сильнее.
- [ ] Проверить зеркальную схему AMBUSH при нескольких seed, чтобы бой не ощущался одинаковым. Убедиться, что подсказка о типе комнаты читаема.
- [ ] В магазине нельзя покупать без достаточного числа душ; кнопка выхода открывает следующий бой.
- [ ] Закончить все шесть фаз. Победа и заработанные осколки отображаются корректно, постоянные улучшения сохраняются после перезапуска.
- [ ] В отдельном прогоне намеренно проиграть: поражение и перезапуск работают, временные реликвии не сохраняются.

## Рывок и подсказки управления (PR #97)
- [ ] `Space` и кнопка `DASH` мышкой работают одинаково; направление задаётся последним движением.
- [ ] Во время рывка виден след, на короткое время не проходит урон от врагов и снарядов.
- [ ] Враги ближнего боя показывают круг опасности перед ударом; рывок из круга предотвращает урон.
- [ ] Дальнобойный враг сначала показывает линию прицеливания; после рывка снаряд летит в старую точку и проходит мимо.
- [ ] До окончания перезарядки нельзя выполнить второй рывок; таймер читаем.
- [ ] У краёв арены герой не выходит за границы и не тратит перезарядку на рывок без перемещения.
- [ ] Рывок недоступен при выборе реликвии, в магазине и после поражения.
- [ ] `H` и кнопка `HELP / H` открывают справку; симуляция останавливается, клики не проходят сквозь окно; `CONTINUE` возвращает в бой.
- [ ] После перезапуска попытки перезарядка рывка обнулена.

## Сложности, звук, метапрогрессия
- [ ] Hard и Nightmare реально повышают давление врагов и босса, но игра остаётся проходимой; записать субъективные трудности.
- [ ] Награда осколками за фазу: Normal +1, Hard +2, Nightmare +3; разовые достижения не выдаются повторно.
- [ ] Mute и +/- громкости действуют сразу и сохраняются после закрытия игры; звуки не раздражают при серии быстрых атак.
- [ ] Статистика побед/поражений и достижения корректны после нового запуска.
- [ ] На экране 1152×648 и при уменьшении окна текст, карточки, подсказки, цифры урона и окно торговца остаются читаемыми.

## Как сообщать о проблеме
Для каждого дефекта указать **сборку (run/SHA), сложность, фазу/комнату, последовательность действий, ожидаемый и фактический результат**, скриншот или видео при наличии и критичность: `blocker` / `high` / `medium` / `low`.

**Релизная граница:** не отмечать ручной QA завершённым, пока не подтверждены реальные прогоны хотя бы Normal и Nightmare, проверка сохранений, UI и Windows EXE.
