# Состояние проекта

Дата: 2026-10-28. Прототип: v0.2.
Статус: исходная сборка создана в ZIP; перенос в GitHub проводится отдельно, не считать полным до проверки scripts/main.gd.

## Реализовано в архиве v0.2
- Экран старта, игровая сессия день → ночь → алтарь → победа/поражение.
- Дневные волны, две башни и экономика маны/душ.
- Ночной платформенный уровень, камни маны, два врага, хранитель, Камень Бездны и портал.
- Пауза P, ремонт R, обмен маны на души C.
