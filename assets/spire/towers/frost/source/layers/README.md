# Ледяной обелиск — первый редактируемый арт-пакет

Подготовлены 6 новых оригинальных SVG-кандидатов, холст **128×128**, два слоя (`base` и `weapon`) для каждого из трёх уровней. Рост башни виден по силуэту: первая форма — один обелиск; вторая — боковые кристаллы и усиленный пьедестал; третья — высокая ледяная корона, рунические камни и осколки.

Исходники: `assets/spire/towers/frost/source/layers/`.

Экспорт PNG без потери оригиналов:

```bash
godot --headless --path . --script res://tools/export_frost_layers.gd
```

Результат: `build/art-preview/frost/` — девять PNG (три базы, три оружия, три совмещённых). Проверка Godot CI требует точные 128×128, непрозрачные детали на прозрачном фоне, отличия соседних уровней, успешный PNG round-trip.

**Не производственный арт:** эти SVG пока геометрические прототипы. Потребуется художественная доработка, сравнение с пользовательским эталоном и тест читаемости на карте. Действующий Frost tower по-прежнему использует временную Spark-графику, и эта ветка **не изменяет** `td_tower_visuals.gd`, характеристики, системы сохранений или игровой рендер. Исходники должны остаться в Git для повторного экспорта и следующей итерации.
