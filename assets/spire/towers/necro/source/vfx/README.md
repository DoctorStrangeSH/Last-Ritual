# Некромантские эффекты Алтаря душ — исходники

Новые оригинальные редактируемые SVG, предназначенные для следующих production-проходов:

| Файл | Кадры | Размер кадра | Тип |
| --- | ---: | --- | --- |
| `soul_projectile_8f.svg` | 8 | 32×32 | полёт души со светящимся черепом |
| `soul_impact_8f.svg` | 8 | 64×64 | зелёный взрыв и рассеивающиеся души |

Каждый исходник — цельный 8-кадровый горизонтальный атлас с прозрачным фоном. Базовый стиль: призрачный зелёный, кость, чёткая пиксельная геометрия. Анимации **не подключены в runtime**: их художественный результат необходимо отдельно оценить, сравнить с пользовательским эталоном и при необходимости переделать.

Воспроизводимый экспорт PNG (Godot 4.4.1):
```bash
godot --headless --path . --script res://tools/export_necro_vfx.gd
```

Результат: `build/art-preview/necro-vfx/soul_projectile_8f.png` и `soul_impact_8f.png`. Экспортёр проверяет 8 непустых, прозрачных и попарно уникальных кадров, размеры и повторное открытие PNG. Экспорт также запускается в PR CI.

**Оригинальный пользовательский концепт v0.5** в этот набор не включён. Он всё ещё ждёт бинарной загрузки в Git. Не путать новые источники с пользовательским эталоном, не подменять текущую игру до приёмки.
