# Алтарь душ — сохранённый пятикадровый Pixel Art (review only)

## Происхождение
- Исходный Git blob: `a5e4257822b8fb358249aace958a0bf3f6e30d0f`, из ветки PR #316 (`38c17405d387a3b173e1ec4527aa836aa910a354`).
- Файл: `approved_assembled_5f.png`, 320×88 пикселей.
- Кадры слева направо: L1, L2, L3, Жнец (siege), Легион (swarm).
- Исходные байты PNG **не менялись**: содержимое повторно использует тот же Git blob, чтобы сохранить историю.
- Существующий концепт владельца остаётся в `source/concepts/`; наличие этого atlas не заменяет персональную визуальную приёмку владельца.

## Режим использования
- **Не подключён к игровому рендеру.** В main используются approved whole-tower PNG L1/L2/L3/Reaper и production fallback для Legion.
- Этот atlas — цельные спрайты, не отдельные base/weapon, **не восемь направлений оружия**.
- **Не утверждать модульный арт только из наличия atlas.** `manifest.json: runtime_enabled=false`.
- Архивный PR #316 был закрыт из-за устаревшей интеграции и красного CI; переносится **только ресурс PNG** с отдельным строгим тестом, а не его старый код.
- Редактируемого исходника Aseprite в Git нет. PNG служит исходным растровым ассетом для извлечения и референсом; не создавать фиктивный .aseprite.

## Экспорт производных для проверки
```bash
python -m pip install Pillow
python tools/export_soul_altar_review_frames.py
```
Результат: `build/soul-altar-assembled-review/frames/` (пять 64×88 и пять 128×176 nearest-neighbour PNG). Папка build не предназначена для runtime.
