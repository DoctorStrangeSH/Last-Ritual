# Ледяной обелиск — исходники модульного Pixel Art

Актуальный воспроизводимый источник нового модульного кандидата: `tools/generate_frost_modular_candidates.py`.

Он создаёт:
- три неподвижных основания 128×128 (L1–L3);
- три оружейных атласа по восемь направлений (обычный, Мороз, Метель);
- шесть анимационных VFX strips (projectile/impact для каждой ветви);
- root manifest со статусом `review_candidate` и `runtime_enabled=false`.

PNG находятся в `assets/spire/towers/frost/candidate/`; исходный процедурный код хранится в Git. Пивот оружия — (64,90), ground anchor — (64,118), порядок направлений — N, NE, E, SE, S, SW, W, NW.

**Важно:** старые заметки о шести SVG-слоях описывали ранний геометрический прототип. SVG-файлы и Aseprite-проект в текущем репозитории отсутствуют; не считать их существующими и не создавать фиктивные исходники. Python-генератор является текущим редактируемым источником.

Новый набор — только художественный кандидат. Он не включён в игровой рендерер. Действующие экспериментальные PNG остаются без изменений до отдельного одобрения и runtime PR.
