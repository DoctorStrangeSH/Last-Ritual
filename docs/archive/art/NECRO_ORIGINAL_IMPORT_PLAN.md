# Алтарь душ — оригинальная графика вместо упрощённых SVG

Эта ветка добавляет **проверяемый импорт оригинальных растровых файлов**, а не ещё одну рисованную SVG-имитацию.

## Исходные материалы
- `LastRitual_SoulAltar_Source_v0.5.zip` с PNG 1448×1086, SHA256 `fa73a1ff2e771c2bc5c7a4df7be04b71654f1d802fe2645e3451df0da641db40`.
- `SoulAltar_Original_Art_Sprites.zip` — 5 прозрачных детализированных PNG, исходные SHA256 каждого проверяются через MANIFEST.json.
- `SoulAltar_Full_Art_Pack.zip` — локально собранный **16-файловый набор**: 5 исходных HD-спрайтов, 5 игровых 192×192, 3 восьмикадровых idle-атласа, 2 VFX-атласа, UI-иконка. В комплект входят исходные пять PNG, скрипт экспорта на Pillow и манифест SHA256.

## Импорт исходников
```bash
pip install Pillow
python tools/import_necro_original_art.py SoulAltar_Original_Art_Sprites.zip --concept soul_altar_tower_concept_v05.png
python tools/install_necro_full_pack.py SoulAltar_Full_Art_Pack.zip
```
Запускаются из корня репозитория. Оба импортёра **проверяют SHA256 перед записью, не перезаписывают изменённые файлы**.

## Проверка реального прогресса
- ✅ 5 оригинальных детализированных PNG и 16 результирующих PNG подготовлены локально; набор можно скачать из разговора.
- ✅ Добавлены и отслеживаются Git-инструменты безопасной загрузки и проверки.
- ⏳ **Бинарные оригиналы пока не присутствуют в git main**. Инструмент не способен сам загрузить файл из чата/Library в GitHub без передачи бинарных байт. Не утверждать обратного.
- ⏳ Рендер `necro` в EXE **пока использует предыдущие экспериментальные PNG**; нельзя удалять их, пока 16 новых файлов не закоммичены и Godot CI не проверил замену.
- ⏳ Анимационные VFX из полного пакета — исходно-текстурированные кандидаты. Для визуальной production-приёмки их ещё нужно сравнить с пользовательским художественным стилем. Должны иметь прозрачный фон, 8 кадров каждый.

## Когда можно удалять старые заглушки
Только после коммита оригинала и новых PNG в Git, smoke-тестов Godot, visual QA в Windows и переключения runtime. До тех пор удаление ломает игру и не отвечает просьбе сохранить оригинал.
