# Алтарь душ: первые авторские VFX в runtime

В этом этапе подключены два оригинальных экспортированных PNG из сохранённых SVG-исходников:

- `assets/spire/towers/necro/vfx/soul_projectile_8f.png` — 8 кадров, 32×32 (256×32).
- `assets/spire/towers/necro/vfx/soul_impact_8f.png` — 8 кадров, 64×64 (512×64).

Точное происхождение: review-ветка `art/necro-png-preview-a466342bf7f0`; редакторские SVG находятся в `assets/spire/towers/necro/source/vfx/`. Слои `base` и `weapon` пока не подменяются: корпус башни продолжает использовать прежний совместимый игровой арт.

`td_tower_visuals.gd` направляет только `necro` projectile/impact на новые атласы и устанавливает корректные размеры кадра. В `topdown_td_prototype.gd` снаряд и удар воспроизводят 8 кадров по прогрессу существующего trail. Процедурный всплеск душ остаётся резервной визуализацией при отсутствии текстуры. Боевой урон, способности, затраты, cooldown, сохранения и другие школы не меняются.

Автоматические smoke checks проверяют импорт PNG на всех трёх уровнях, точные размеры и индекс последнего кадра. **Не считать финальной художественной приёмкой** — качество и читаемость на масштабе 1× требуют тестирования Windows EXE.

Отдельная задача: крупный оригинальный пользовательский концепт v0.5 по-прежнему необходимо загрузить в Git; он не является частью этих двух экспортных атласов.
