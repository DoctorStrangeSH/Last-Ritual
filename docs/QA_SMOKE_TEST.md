## 1. Меню и новый забег
- [ ] Открывается главное меню, текст читаем, кнопки работают мышью.
- [ ] Можно открыть достижения, таланты, сложность/наследие и вернуться без потери управления.
- [ ] Настройки громкости работают и не влияют на боевые действия.
- [ ] Новый забег запускается, новая кампания начинается с дня 1.

## 2. Дневная оборона
- [ ] Все три карты башен снизу выбираются мышью и строятся на допустимом месте.
- [ ] Не хватает маны / неверная позиция: строительство запрещено, причина понятна.
- [ ] Нажатие на башню показывает информацию, улучшение и продажа работают.
- [ ] Враги движутся по линиям, башни стреляют, работают эффекты и HP.
- [ ] Ремонт крепости работает, окончание здоровья стен приводит к поражению.
- [ ] После завершения дня начинается соответствующая ночь без зависаний.

## 3. Ночная экспедиция
- [ ] A/D, W/Space, ЛКМ, ПКМ, H, Shift работают согласно описанию и расходу маны.
- [ ] ПКМ показывает дугу и перезарядку, способность не применяется без маны.
- [ ] Ловушки предупреждают об активации; платформы и тайники доступны.
- [ ] Маг Света выпускает снаряды, их можно избегать.
- [ ] Со второй ночи Проклятый громила показывает предупреждение рывка и не меняет направление атаки после старта.
- [ ] С третьей ночи Проклятый стрелок показывает «ЗАРЯД!» и фиолетовую линию, стреляет после предупреждения.
- [ ] Босс получает урон и умирает; камень подбирается; портал доступен после получения камня.
- [ ] Смерть героя ведёт к поражению, мёртвый герой не может активировать портал.

## 4. Алтарь и метапрогресс
- [ ] После ночи показываются три дара (или легендарный выбор в предусмотренную ночь), карты кликабельны.
- [ ] Выбранный дар применяется один раз; синергии появляются только при выполненных условиях.
- [ ] На алтаре работают улучшения, обмен ресурсов, переход в следующий день.
- [ ] Продолжение из главного меню загружает контрольную точку алтаря, не ломает ресурсы/день.
- [ ] Повторный забег сбрасывает временные бонусы, а постоянные таланты сохраняются.
