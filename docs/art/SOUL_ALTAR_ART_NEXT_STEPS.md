# Алтарь душ — арт-доработка: что сделано и что дальше

Компактная передача для следующего ИИ. Не хронология: хронология — в `docs/AI_HANDOFF_PIXEL_ART.md` и `docs/DECISIONS.md`. Обновляй этот файл вместо добавления новых абзацев.

## Рамки (подтверждены владельцем)
- Единый детальный тёмно-фэнтезийный пиксель-арт: золото, фиолетовая магия, черепа. Новых концептов Алтаря не создавать.
- Алтарь душ — эталон качества для остальных башен (`bone`, `fire`, `frost`).
- Прогрессия L1 → L2 → L3 → выбор Жнец (`siege`) / Легион (`swarm`). Основание неподвижно, вращается только оружие (8 направлений).
- Всё модульное остаётся в `assets/spire/towers/necro/candidate/`, `runtime_enabled=false`, пока владелец не примет набор в Windows.

## Единственный исходник арта
`tools/generate_necro_modular_candidates.py`. Правка → `python tools/generate_necro_modular_candidates.py` → `--verify`. Внимание: запуск без `--verify` перезаписывает все 12 PNG, а другая версия Pillow даёт другие байты при тех же пикселях. Перед коммитом верни `git checkout --` для файлов, которые не менял.

Приёмка: `python tools/render_necro_modular_preview.py --all-levels --scale 1|2`, сцена `scenes/dev/soul_altar_modular_motion_preview.tscn`, `LastRitual-ArtPreview.exe` из релиза `windows-preview`.

## Дальше (по одному PR)
1. Обычное оружие: призма/руническая корона вместо бруска, проверка на листе 1×.
2. Основания L1–L3: выше и компактнее, различимые силуэты уровней, золотые шпили и руны крупнее.
3. Золото и руны: рампа 3–5 тонов, контрастные фиолетовые руны, единая обводка темнее материала.
4. Доработка Легиона (меньше шума, роевая композиция) и Жнеца (черепа/цепи, свечение).
5. Читаемость на 1× и масштаб на площадке (ориентир ~120 px по высоте в игре).
6. Только после приёмки владельцем: перенос в production manifest, `runtime_enabled=true`, переключение рендера, Windows QA, отдельный PR очистки старых спрайтов.

## Запреты
Не включать `runtime_enabled`, не менять баланс/цены/сохранения в арт-PR, не вращать башню целиком, не масштабировать нецелым коэффициентом, не удалять арт без поиска ссылок, не выдумывать Aseprite-исходники, не заявлять визуальную приёмку по CI.
